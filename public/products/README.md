# Папка фотографий товаров

Сюда положите фото товаров. Каждый товар — в своей подпапке по `slug` (см. `data/products.ts`).

## Соглашение по файлам

В каждой подпапке создайте файлы с именами:

- `01.jpg` — главное фото (используется в карточке каталога и hero страницы товара)
- `02.jpg`, `03.jpg`, `04.jpg` — дополнительные фото для галереи на странице товара

Форматы: `.jpg`, `.png`, `.webp`. Рекомендуется `.webp` или `.jpg` ~80% качество, разрешение от 1200×1200.

## Подпапки

- `arseva-pro-max/` — ARSEVA Pro Max (перкуссионный)
- `arseva-pro-max-carbon/` — Pro Max Carbon
- `arseva-pro-max-plus/` — Pro Max Plus
- `arseva-pro-relax/` — PRO RELAX (шея и плечи)
- `arseva-pro-relax-2/` — PRO RELAX 2
- `arseva-foot-massager/` — массажер для ног
- `arseva-pro-comfort/` — массажер для глаз PRO COMFORT
- `arseva-pro-comfort-steam/` — PRO COMFORT с паром
- `arseva-flexroll/` — FlexRoll

Если фото для товара ещё нет, отображается премиальный SVG-плейсхолдер. Когда вы положите файл — он автоматически появится на сайте.

## Откуда взять фото

Скачайте оригиналы со страниц товаров на Ozon (правый клик → «Сохранить изображение»). Ozon разрешает использовать собственные фото товара продавцу — то есть фото, которые вы туда сами загрузили.
